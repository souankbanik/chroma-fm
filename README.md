# CHROMA FM

A visual radio station for colors that don't exist.

A long-form scroll experience in 16 channels — bold editorial / Swiss poster typography, flat saturated ink, circles, lines and kinetic type.

**Live:** https://souankbanik.github.io/chroma-fm/

## Stack

- Vite, vanilla JS
- GSAP + ScrollTrigger, Lenis
- Three.js (one refracting glass sphere, chapter 06)
- Archivo Black · Inter Tight · Instrument Serif · IBM Plex Mono (via Fontsource)

## Run

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # outputs dist/ (base path /chroma-fm/ for GitHub Pages)
```
